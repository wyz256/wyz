王宇智的JavaScript · fetch 获取接口数据

使用原生 fetch + async/await 请求允许跨域（CORS）的公开接口，数据渲染到页面。结果同时输出到控制台（F12 查看）

一、fetch 使用要点

① fetch(url) 返回 Promise，配合 async/await 可用同步写法处理异步请求
② response.ok 为 true 表示 HTTP 状态码在 200-299 之间，请求成功
③ response.json() 把响应体解析为 JS 对象（也是 Promise）
④ 用 try / catch 捕获网络错误，用状态提示区分 加载中 / 成功 / 失败

接口：https://jsonplaceholder.typicode.com/users
