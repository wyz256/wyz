二、本页用到的 Canvas 2D 知识点

矢量图形
用 arcTo 封装圆角矩形，绘制层带、节点卡片与胶囊；createLinearGradient 生成渐变填充。
贝塞尔曲线
bezierCurveTo 画跨层连线，再用三次贝塞尔公式求出曲线上任意比例的点，实现数据流动光点。
线条样式
setLineDash 区分运维支撑虚线，lineWidth / globalAlpha 区分普通链路与高亮链路。
文字与提示
fillText / textAlign / textBaseline 排版节点文字，并在画布内绘制悬停提示框。
坐标变换
setTransform 一次性把「1200×820 逻辑坐标」映射到缩放后的高清画布，点击时反向换算做命中检测。
动画与导出
requestAnimationFrame + 动画时间 t 驱动光点循环，toDataURL() 把整张架构图导出为 PNG。

三、电商全站系统分层说明

① 用户终端层：PC 商城、H5/小程序、APP、商家运营后台四类入口，统一请求后端
② 接入网关层：CDN 静态加速 → Nginx/SLB 负载均衡 → API 网关（鉴权、路由、限流、熔断）
③ 业务服务层：用户、商品、搜索、购物车、订单、支付、库存、营销、物流、消息十个领域服务，构成完整交易主链路
④ 数据存储层：MySQL 持久化、Redis 缓存、Elasticsearch 检索、MQ 异步解耦、OSS 文件存储
⑤ 基础设施层：容器编排、日志监控、配置中心、定时任务与数据仓库，为全站提供部署、观测与分析能力
绘制逻辑：每帧 clearRect → 背景网格 → 层带 → 链路（线 / 箭头 / 粒子 / 标签）→ 节点卡片 → 交易链路 → 图例 → 悬停提示
