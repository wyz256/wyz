Font Awesome
字体图标

Font Awesome 采用「图标字体」方案：把每个图标做成字体里的一个字形，通过 CSS 类名像调用字体一样调用图标。本页面资源已本地化到 cdn/font-awesome/，无需联网即可使用。

字体图标要点

· 图标即文字，可用 font-size 控制大小
· 用 color 即可改变颜色
· 一次加载字体文件，全图标可用

原理：图标字体 Icon Font

字体图标把图标绘制成矢量字形并打包成 Web 字体（woff2）。CSS 通过 @font-face 引入字体，再用 ::before 伪元素输出对应字符，就能「写」出一个图标。

① 引入字体 CSS

all.min.css 内通过 @font-face 声明 woff2 字体文件。

② 用类名调用图标

<i class="fa-solid fa-heart"> 对应字体中的一个字形。

③ 像文字一样样式化

font-size、color、阴影等文字属性全部适用。

<link rel="stylesheet" href="cdn/font-awesome/css/all.min.css"> <i class="fa-solid fa-heart"></i> /* 红心 */ <i class="fa-brands fa-github"></i> /* 品牌图标 */
