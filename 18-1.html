一、本页用到的 Canvas 2D 知识点

画布与上下文
canvas.getContext("2d") 取得画笔；用 devicePixelRatio 放大位图、setTransform 还原 CSS 坐标，避免高清屏模糊。
文字绘制
font / textAlign / fillText / strokeText 绘制文字，createLinearGradient 做流光渐变，shadowBlur + shadowColor 做发光。
坐标系变换
save() / restore() 保护画笔状态，translate 平移到中心、scale 实现文字呼吸缩放与倒影翻转。
路径与图形
ellipse() 画旋转椭圆轨道，arc() 画星点与光球，createRadialGradient 画背景光晕。
透明度与叠加
globalAlpha 控制星星明暗与倒影透明度，配合 sin() 函数实现周期性呼吸效果。
动画循环
requestAnimationFrame 逐帧重绘；用两帧时间差 dt 更新位置，保证不同刷新率下速度一致。

二、动画实现思路

① 每帧先 clearRect 清空，再依次绘制 背景渐变 → 网格 → 星点 → 椭圆轨道 → 文字 → 倒影 → 火花粒子，绘制顺序决定遮挡关系
② 所有运动都由动画时间 t 驱动：sin(t) 控制呼吸与浮动，t * speed 控制轨道旋转，粒子用 dt 累加位置与重力
③ 暂停时只停止 t 与粒子更新，循环仍在运行，因此画面保持可见且控件随时可恢复
④ 火花数组随时间移除过期粒子，避免数组无限增长造成卡顿
