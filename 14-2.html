王宇智的JavaScript · 六种基本数据类型

使用 typeof 运算符检测数据的类型，结果会写入下方卡片，同时输出到控制台（按 F12 查看）

1. String 字符串

typeof 结果：string 
var wyz_str = "王宇智";

用单引号或双引号包裹的一串文本

2. Number 数值

typeof 结果：number 
var wyz_num = 3.14;

整数和小数统称数值，不区分整型与浮点型

3. Boolean 布尔

typeof 结果：boolean 
var wyz_bool = true;

只有 true 和 false 两个值，表示真和假

4. Undefined 未定义

typeof 结果：undefined 
var wyz_undef;
// 只声明，未赋值

变量声明后没有赋值，它的类型就是 undefined

5. Null 空

typeof 结果：object（历史遗留） 
var wyz_null = null;
// 表示“空值”

表示“什么都没有”，通常用于主动清空一个变量

6. Object 对象

typeof 结果：object 
var wyz_obj = {
    wyz_name: "王宇智",
    wyz_age: 18
};

花括号包裹的“键值对”集合，数组也属于对象

注意：null 用 typeof 检测时返回 "object"，这是 JavaScript 早期设计留下的 历史遗留问题；null 本身并不是对象，它表示空值。
