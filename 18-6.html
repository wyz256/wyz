① 智能客服系统流程图

flowchart TD
    U["用户"] --> Q["用户提问<br/>多渠道接入 Web/APP/微信"]
    Q --> I["意图识别与语义理解<br/>NLU / 槽位填充"]
    I --> D{"是否需要<br/>检索知识库"}
    D -->|"是"| K["知识库检索 RAG<br/>向量召回 + 关键词"]
    K --> C["知识切片与重排<br/>引用溯源"]
    C --> G["答案生成 LLM<br/>结合上下文"]
    D -->|"否(闲聊/FAQ)"| G
    G --> A["答案审核与合规校验"]
    A -->|"不确定/敏感/复杂"| H["人工坐席转接"]
    A -->|"通过"| O["回复用户"]
    H --> O
    O --> F["会话日志与用户反馈"]
    F --> E["评价分析<br/>模型与知识库持续优化"]
    E --> K

② 智能客服系统 ER 图

erDiagram
    USER ||--o{ SESSION : "发起"
    USER ||--o{ FEEDBACK : "提交"
    SESSION ||--o{ MESSAGE : "包含"
    MESSAGE }o--|| QA : "命中"
    DOCUMENT ||--o{ CHUNK : "切分为"
    CHUNK }o--|| EMBEDDING : "生成"
    QA }o--|| DOCUMENT : "引用"
    AGENT ||--o{ SESSION : "处理"

    USER {

    }
    SESSION {
        string session_id PK

        string channel
    }

        string msg_id PK
        string content
        string role
        datetime send_time
    }
    QA {
        string qa_id PK
        string question
        string answer
        float score
    }
    DOCUMENT {
        string doc_id PK
        string title
        string source
    }
    CHUNK {
        string chunk_id PK
        text content
    }
    EMBEDDING {
        string emb_id PK
        vector value
        string chunk_id FK
    }
    AGENT {
        string agent_id PK
        string name
        string skill
    }
    FEEDBACK {
        string fb_id PK
        int rating

    }

实体：用户 / 会话 / 消息 / 问答对 / 文档 / 切片 / 向量 / 坐席 / 反馈；关系含一对多、引用与外键约束。

本页用到的 Mermaid 知识点

本地引入
用 <script src="cdn/mermaid.min.js"> 引入，再调用 mermaid.initialize({startOnLoad:true}) 初始化。
流程图 flowchart
flowchart TD 自上而下；[] 矩形、{} 判断、-->|标签| 带标签边，style 给节点着色。
ER 图 erDiagram
用 ||--o{ 等基数表示一对多关系；实体属性块内用 PK / FK 标记主键外键。
文本即图
图由领域特定语言(DSL)描述，写在 class="mermaid" 的元素内，便于版本管理与协作。
自动渲染
startOnLoad:true 时 Mermaid 在页面加载后自动把每个 .mermaid 元素转换为 SVG。
主题与样式
可设 theme:'default'/'dark'，并用 securityLevel:'loose' 允许富文本标签（如 <br/>）。
