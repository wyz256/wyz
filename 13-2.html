INLINE SVG · LUCIDE

Lucide 图标
SVG 方式

Lucide 采用「内联 SVG」方案：每个图标就是一段矢量 SVG 标记，直接写进 HTML。本页面图标源文件已本地化到 cdn/lucide/，无需联网即可使用。

SVG 图标要点

· 纯矢量，任意缩放不模糊
· 可用 CSS 直接改色、加滤镜
· 无需加载字体，按需内联

原理：内联 SVG Inline SVG

SVG 与 HTML 同属 XML 家族，可以像普通标签一样嵌入页面。Lucide 的每个图标都是一段带 viewBox 的矢量标记，使用 stroke="currentColor" 跟随文字颜色，天然适配 CSS 主题。

<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round"> <path d="M20 6 9 17l-5-5" /> /* 对勾 */ </svg>

字体图标（Font Awesome）

图标 = 字形，靠 font-size / color 控制；一次加载整套字体文件；颜色单一，难以局部着色。

SVG 图标（Lucide）

图标 = 矢量标签，可用 width / height / fill / stroke / filter 精细控制；随用随写，无字体请求。
