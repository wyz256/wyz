CSS3 3D动画演示

1. 3D 变换函数 - rotateX / rotateY / rotateZ

CSS3 可以在三维空间中旋转元素：rotateX() 绕水平轴旋转，rotateY() 绕垂直轴旋转，rotateZ() 绕屏幕法线旋转。鼠标悬停查看效果。

rotateX(180deg)
rotateY(180deg)
rotateZ(180deg)
rotate3d(1,1,0,90deg)
transform: rotateX(180deg); transform: rotateY(180deg); transform: rotateZ(180deg);
注意：父元素需要设置 perspective（透视），子元素的 3D 旋转才有纵深感。

2. perspective 透视属性

三个卡片执行相同的 transform: rotateY(45deg)，但父容器分别设置不同的 perspective 值。值越小，3D 效果越强烈。

.parent { perspective: 600px; } .child { transform: rotateY(45deg); }

4. 翻转卡片与 backface-visibility

鼠标悬停，卡片绕 Y 轴翻转 180°。正面和背面都设置了 backface-visibility: hidden，保证各自只在自己朝向观察者时可见。

3D 相关属性对比表

属性 / 函数 作用 常用值
perspective 设置透视距离，产生近大远小效果 200px ~ 1200px
perspective-origin 设置透视消失点的位置 50% 50%（默认居中）
transform-style 子元素是否处于同一 3D 空间 preserve-3d / flat
rotateX / rotateY / rotateZ 绕 X / Y / Z 轴旋转 角度值，如 45deg
rotate3d(x, y, z, angle) 绕自定义轴旋转 rotate3d(1, 1, 0, 90deg)
translateZ 沿 Z 轴位移（靠近/远离观察者） 长度值，如 75px
backface-visibility 元素背面是否可见 visible / hidden
animation 配合 @keyframes 制作连续 3D 动画 wang_spin 8s infinite linear
