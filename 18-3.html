二、本页用到的 SVG 知识点

矢量与响应式
用 <svg viewBox> 定义 1200×900 逻辑坐标系，preserveAspectRatio 配合 CSS 宽度实现自适应缩放。
数据驱动绘制
用 createElementNS 在 JS 中按节点 / 链路数据批量创建 rect、path、text，比手写静态 SVG 更易维护。
贝塞尔与箭头
链路用三次贝塞尔 path，<marker> 定义按层着色的箭头，marker-end 自动指向终点。
流动动画
stroke-dasharray + stroke-dashoffset 关键帧让虚线持续滚动，表现请求 / 数据自顶向下流动。
交互联动
SVG 是 DOM，直接给 <g> 绑定 click / mouseenter，用 classList 切换高亮，无需手动命中检测。
导出
XMLSerializer 序列化 SVG 下载；再用 Image + <canvas> 栅格化为 PNG，二者均为纯前端实现。

三、科研方向说明（RAG 智能客服）

① 知识库构建（Knowledge Construction）：多源文档解析（PDF/网页/OCR）→ 语义切片（Chunking）→ 向量化 + 知识图谱三元组抽取 → 质量校验与去重治理。
② 检索增强生成（RAG Core）：查询改写（Query Rewriting）→ 混合检索（稠密向量 + 稀疏 BM25）→ 重排（Cross-Encoder Reranker）→ 证据溯源（Citation）→ LLM 生成，是回答质量的核心链路。
③ 科研评测闭环（Research Flywheel）：自动评测（相关性 / 忠实度 / 完整性）↔ 人工标注 → Bad-case 错误归因 → 幻觉检测与可解释性 → 领域自适应与持续学习，结果回流优化知识库与模型，形成飞轮。
④ 基础支撑：LLM / Embedding 模型服务、GPU 推理算力、向量索引（ANN）、全链路监控与合规审计，为科研实验提供可复现、可观测的工程底座。
