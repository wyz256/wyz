CSS 单位长度演示

1. 绝对单位 - px（像素）

px是最常用的绝对单位，表示屏幕上的一个物理像素点。

宽200px 高50px
width: 200px; height: 50px;

2. 相对单位 - em

em相对于父元素的font-size。例如：父元素font-size:20px，则1em=20px。

宽10em 高2.5em
font-size: 20px; width: 10em; (200px)

3. 相对单位 - rem（root em）

rem相对于根元素（html）font-size。:root设为16px，则1rem=16px。

宽15rem 高3rem
width: 15rem; (240px) height: 3rem; (48px)

4. 相对单位 - %（百分比）

%相对于父元素的对应属性值。

宽50%
width: 50%;（父元素宽度的50%）

5. 视窗单位 - vw、vh

vw = 视窗宽度的1%，vh = 视窗高度的1%。

宽30vw
高5vh
width: 30vw; height: 10vh;

6. 视窗单位 - vmin、vmax

vmin = 视窗较小边的1%，vmax = 视窗较大边的1%。

20vmin
15vmax
width: 20vmin; height: 10vmin;

7. 字符单位 - ch、ex

ch = 字符"0"的宽度，ex = 字符"x"的高度。

这是20ch宽度的文本内容
这是20ex宽度的文本内容
width: 20ch; width: 20ex;

长度单位对比表

单位 类型 相对于 说明
px 绝对 屏幕像素 固定大小，精确控制
em 相对 父元素font-size 可继承，常用于排版
rem 相对 根元素font-size 统一缩放，响应式常用
% 相对 父元素 根据父容器自适应
vw/vh 视窗 视窗宽高 全屏相关布局
vmin/vmax 视窗 视窗最小/最大边 保持比例的响应式
ch 字符 "0"的宽度 基于字符的宽度
ex 字符 "x"的高度 基于字符的高度
